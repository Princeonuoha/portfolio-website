# princeonuoha.com

Personal portfolio of Prince Onuoha, DevOps Engineer in Berlin.

Plain HTML, CSS and JavaScript. No build step.

## Run locally

```bash
python -m http.server 5500
```

Then open http://localhost:5500.

## Files

- `index.html`: all content and sections
- `styles.css`: design tokens, dark/light themes, layout
- `script.js`: starfield, theme toggle, scroll reveal, diagram hover, quick-contact panel
- `assets/prince.jpg`: hero portrait
